# Installer EKS Module Release v3.3.1

Welcome to the latest release of the `installer-eks` module of [`SIGHUP Distribution`](https://github.com/sighupio/distribution)
maintained by team SIGHUP.

This release introduces the `vpn_furyagent_path` variable to the VPN Terraform module to avoid embedding furyagent binaries in the repository. When the variable is not set, we use `curl` to download the release from github, so it is required that the host system has it installed or else it will break.
