# Installer EKS Module Release v3.3.0

Welcome to the latest release of the `installer-eks` module of [`SIGHUP Distribution`](https://github.com/sighupio/distribution)
maintained by team SIGHUP.

This release introduces the `workers_group_defaults` variable to the EKS Terraform module, allowing for centralized management of default settings for AWS Instance Metadata Service (IDMS). [PR #83](https://github.com/sighupio/installer-eks/pull/83)
